Proposed Architecture: ESP32-S3 Voice Assistant

MVP is turn-based voice. Interfaces are shaped so keyword wake and realtime streaming can be added later.

ESP32-S3 Firmware
UI

Digital avatar page

Idle, listening, thinking, speaking, error animations. Minimal captions.

Mic

I2S audio capture

Record short mono PCM chunks after touch/button wake.

Net

HTTPS client

POST audio to backend proxy with device token, not OpenAI API key.

Out

I2S speaker playback

Play backend TTS audio while avatar mouth/face animates.

State

Assistant state model

Audio/network tasks update state; LVGL timer renders it safely.

Backend Proxy
1

Receive audio

Validate device token, store request logs without leaking secrets.

2

Transcribe

Speech-to-text model turns user audio into text.

3

Reason

Configured LLM answers using assistant prompt and optional tools.

4

Synthesize

TTS returns audio in a device-friendly format.

5

Respond

Return audio plus short status/caption text for the avatar page.
